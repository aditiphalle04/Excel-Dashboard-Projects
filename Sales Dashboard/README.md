# Sales Dashboard

## Overview

This project is an interactive Sales Dashboard built in Microsoft Excel using Pivot Tables, Pivot Charts, Slicers, and basic VBA automation.

The dashboard enables users to analyze sales performance, target achievement percentages, and sales trends across different regions and sales executives.

## Dashboard Features

- Interactive city-wise filtering using slicers
- Sales performance tracking
- Target achievement analysis
- Away-from-target percentage analysis
- Dynamic Pivot Tables and Pivot Charts
- VBA-based dashboard interaction

## Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- VBA

## Key Metrics

- Total Sales
- Target Hit Percentage
- Away From Target Percentage
- Sales Executive Performance
